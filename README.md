# Final Year BBQ - deploy on GitHub Pages
The Supabase database is already set up and the admin account is created.
1. Create a PUBLIC GitHub repo and upload everything in this folder (index.html must be at the top level).
2. Repo Settings > Pages > Deploy from a branch > main / root > Save.
3. Supabase > Authentication > URL Configuration > set Site URL to your GitHub Pages link.
4. Admin login: <your-link>/admin.html
Only the project URL + publishable key are in js/config.js. Never add the service_role key.
Change CONTACT_PHONE in js/config.js to your real contact number.
